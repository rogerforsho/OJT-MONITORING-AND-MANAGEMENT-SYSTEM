# System Architecture

## Technology Stack (Per Capstone Manuscript)
- **Web Application:** Next.js (App Router) + TypeScript + Tailwind CSS
- **Mobile Application:** React Native + Expo (Expo Go testing) + TypeScript + NativeWind
- **Backend & Database:** Supabase (PostgreSQL, Supabase Auth, Private Storage, Row Level Security)
- **Design & Prototyping:** Figma
- **Version Control & Collaboration:** GitHub
- **IDE:** Visual Studio Code

*Do not replace these technologies unless explicitly instructed.*

## Architectural Rules
1. **Single Source of Truth:** Centralized Supabase database is the sole authoritative store.
2. **Online-First Operational Model:** The system requires an active internet connection as specified by the manuscript.
3. **Defense in Depth:** Every table enforces strict RLS policies; API services perform server-side assertion checks (`assertCoordinator`, `getAuthUserWithRole`).
4. **Signed Asset Security:** Attendance selfie evidence and report documents use short-lived signed URLs.
5. **8 GB RAM Constraint Optimization:** Cloud-hosted backend infrastructure avoids heavy local database containers, keeping the dev environment fast and lightweight on minimum hardware specifications (i5/Ryzen 5, 8GB RAM).

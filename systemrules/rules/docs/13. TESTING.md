# Test & Evaluation Plan

## Evaluation Standard (ISO/IEC 25010:2023)
The system is evaluated based on four primary software product quality characteristics from **ISO/IEC 25010:2023**:
1. **Functional Suitability:** Functional completeness, functional correctness, and functional appropriateness across all 9 increments.
2. **Performance Efficiency:** Time-behavior, resource utilization, and throughput under real-world usage.
3. **Usability:** Appropriateness recognizability, learnability, operability, user error protection, and user interface aesthetics.
4. **Security:** Confidentiality, integrity, non-repudiation, accountability, and authenticity.  
*(Note: Wording must strictly state that "security-related features were evaluated" rather than claiming full security audit certification.)*

---

## 4 Categories of Testing

### 1. Functional Testing
Verify complete functional correctness for all operations:
- **Authentication & Roles:** Self-registration into `pending` status, Coordinator approval/rejection, role-based page guards.
- **Attendance & Selfie:** Time In / Time Out capture, mandatory camera selfie submission, work schedule cutoff late-status calculation, supervisor verification/rejection.
- **Hour Computation:** Verified attendance calculation, required hours countdown, progress calculation.
- **Documents & Reports:** Pre-deployment requirement submission (Placement Form, Waiver, Student ID), periodic report uploads, Coordinator review and remarks.
- **Evaluations:** Supervisor evaluation submission, scoring rubrics, and feedback recording.
- **Notifications & Announcements:** Automated event notifications, administrative announcement broadcasting.
- **Administration:** User activation/deactivation, system configuration.

### 2. Usability Testing
Evaluated by actual role participants (Students, Coordinators, Supervisors, Program Heads):
- Interface clarity and responsive visual presentation (Teal/Slate modern UI).
- Navigation intuitiveness and task completion efficiency.
- Error prevention and clear visual feedback (loading spinners, empty states, error alerts).

### 3. Compatibility Testing
- **Web Application:** Cross-browser compatibility across Google Chrome, Mozilla Firefox, Microsoft Edge, and Safari on desktop/laptop form factors.
- **Mobile Application:** Android and iOS compatibility via Expo / React Native on camera-enabled smartphones.

### 4. Security-Related Testing
Evaluate protection mechanisms:
- Unauthenticated access rejection (Next.js middleware and Supabase RLS).
- Role-based privilege escalation prevention (IDOR checks on supervisor and student data).
- File storage privacy: private bucket isolation, 60-second signed URL expiration for selfies and submissions.
- Injection and input tampering prevention.

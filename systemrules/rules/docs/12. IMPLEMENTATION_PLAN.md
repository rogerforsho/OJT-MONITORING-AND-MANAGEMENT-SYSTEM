# Agile Implementation Plan

## Methodology
The project follows an **Agile Development Methodology** with continuous testing after each functional increment:
1. Planning & Requirements Analysis
2. System & Interface Design
3. Iterative Development
4. Testing (Functional, Usability, Compatibility, Security)
5. User Feedback & Revision
6. Deployment & Final Review

---

## 9 Functional Development Increments

### Increment 1 — Authentication & Role Management
- User signup and login (Supabase Auth).
- Account status lifecycle: `pending` -> `active` / `rejected`.
- OJT Coordinator approval workflow.
- Secure email password recovery.
- Role-based route protection on web (Next.js middleware) and mobile navigation.

### Increment 2 — Student Profile & OJT Application
- Student registration profile (ICS / IBE courses, student number, 4th-year level).
- Pre-deployment requirement submission (Placement Form, Waiver, Student ID).
- Coordinator requirement checking and verification.
- Partner company setup and supervisor assignment.

### Increment 3 — Attendance & Selfie Submission
- Online Time In / Time Out logging with mobile camera.
- Mandatory front-camera selfie capture as visual evidence.
- Upload to private Supabase storage with signed URL access.
- Company work schedule enforcement and late-status determination.
- Supervisor attendance review and verification/rejection.

### Increment 4 — Rendered-Hour Computation
- Automated server-side calculation of completed internship hours from verified attendance.
- Configurable required hours per academic program (e.g., ICS vs IBE hours).
- Automatic daily hour deductions and time tracking.

### Increment 5 — Digital Document & Report Submission
- Digital submission of periodic OJT accomplishment reports (weekly journals, final reports).
- File type and size validation.
- Coordinator review, remarks, and approval statuses.

### Increment 6 — OJT Progress Monitoring
- Real-time progress dashboard for Students (rendered hours, remaining hours, progress percentage).
- OJT Coordinator cohort progress tracking and completion lists.
- Company Supervisor trainee status view.

### Increment 7 — Performance Evaluation
- Company Supervisor evaluation form with performance scores and qualitative feedback.
- Institutional rubric compliance.
- Coordinator evaluation compilation.

### Increment 8 — Notifications & Announcements
- Centralized event notifications for status changes, approvals, and reviews.
- System Administrator and Coordinator broadcast announcements.
- Unread/read status tracking.

### Increment 9 — Administrative & Departmental Reports
- Program Head department-level summary dashboards (ICS / IBE).
- Coordinator exportable attendance and evaluation summaries.
- System Administrator user and configuration management.
- Final internship record locking (read-only finalization).

# Roles and Permissions

Access is denied unless explicitly allowed. Each user has one role.

| Capability | Student | Coordinator | Supervisor | Program Head | Admin |
|---|---|---|---|---|---|
| Self-register | Yes | No | No | No | No |
| Approve student registration | No | Yes | No | No | No |
| Technical account status management | No | No | No | No | Yes |
| Manage companies | No | Yes | No | No | No |
| Assign student/company/supervisor | No | Yes | No | No | No |
| Record own attendance | Yes | No | No | No | No |
| Scan attendance QR | Yes | No | No | No | No |
| Submit own selfie evidence | Yes | No | No | No | No |
| Review assigned student's selfie | No | Unresolved | Yes | No | No |
| View own progress | Yes | No | No | No | No |
| Monitor student progress | No | Yes | Assigned only | Approved summary scope | No by default |
| Submit own requirements | Yes | No | No | No | No |
| Review submissions | No | Yes | Not by default | No by default | No |
| Evaluate student | No | No | Assigned only | No | No |
| Technical administration | No | No | No | No | Yes |

## Admin Boundary
Admin supports technical access and system operation. Admin does not automatically approve academic requirements, evaluate OJT performance, assign grades, or replace the Coordinator/Program Head.

## Unresolved Permissions
- student visibility of completed evaluations;
- Coordinator visibility of selfie evidence;
- Program Head announcement permission;
- exact export permissions.

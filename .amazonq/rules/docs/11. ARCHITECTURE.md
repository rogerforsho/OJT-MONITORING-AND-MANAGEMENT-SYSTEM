# Architecture

## Stack
- Next.js + TypeScript responsive web
- React Native + Expo + TypeScript mobile
- Supabase backend platform
- PostgreSQL database
- Supabase Auth
- Supabase Storage
- Tailwind CSS web
- NativeWind mobile

## Logical Model
```text
Responsive Web Client ─┐
                       ├── Centralized Supabase Services
Mobile Client ─────────┘        ├── PostgreSQL
                                ├── Authentication
                                └── Private File Storage
```

## Rules
- No separate authoritative database per platform.
- Server/database is authoritative for synchronized persistent records.
- Desktop/laptop means responsive browser access.
- Security-sensitive validation cannot exist only on the client.
- Offline attendance is pending until server synchronization and validation.

## 8 GB RAM Direction
Use cloud-hosted backend services during normal development, avoid duplicate backend stacks, avoid unnecessary native desktop frameworks, and run only services needed for the current task.
